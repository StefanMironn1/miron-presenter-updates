# Miron Presenter — actualizări

Aici stau actualizările pentru Miron Presenter (Biserica Agape Atena).

Aplicația citește `latest.json` și, dacă versiunea e mai nouă, descarcă fișierul `.mpupdate` din `releases/`, îi verifică SHA-256 și îl instalează la repornire.

Adresa de pus în aplicație (Preferințe → Actualizări):

```
https://raw.githubusercontent.com/StefanMironn1/miron-presenter-updates/main/latest.json
```
